# AI Agent Studio Buyer README

AI Agent Studio is a Velocity11-branded source package based on the open-source Dify project by LangGenius. It is intended for technically capable buyers who want to inspect, self-host, or adapt an LLM application development platform.

## What is included

- Source code from the Velocity11 AI Agent Studio fork.
- Original upstream licence and notices from Dify/LangGenius.
- Velocity11 buyer documentation in `BUYER_DOCS/`.
- Setup guidance based on the included upstream Docker and development documentation.

## What this package is not

- It is not a hosted AI service.
- It does not include API keys, model credits or third-party provider accounts.
- It does not guarantee compatibility with every model provider.
- It is not a managed deployment, production hardening or custom integration service.
- It is not newly relicensed by Velocity11 under a blanket Apache 2.0 licence.

## Recommended first steps

1. Read `BUYER_DOCS/VERSION_INFO.txt`.
2. Read the original `LICENSE` and `NOTICE.txt` files.
3. Review `BUYER_DOCS/SETUP_GUIDE.md`.
4. Inspect `BUYER_DOCS/VERIFIED_FEATURES.md` before relying on any advertised feature.

## Support

Support is limited to the packaged files and documentation. See `BUYER_DOCS/SUPPORT_BOUNDARIES.md`.
