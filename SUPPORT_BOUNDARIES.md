# AI Agent Studio Support Boundaries

Velocity11 buyer support for this package is limited to:

- Explaining what files are included in this buyer ZIP.
- Clarifying the documentation included in `BUYER_DOCS/`.
- Pointing to the original licence and attribution notices included with the source.

Support does not include:

- Model-provider account setup or billing.
- API-key provisioning.
- Managed hosting, DevOps, database administration, queues, vector databases or backups.
- Security hardening for a production AI system.
- Custom agents, tools, workflows or integrations.
- Legal advice about licence obligations.
- Guaranteed updates from the upstream Dify project.

AI systems can create operational, security and compliance risks. Buyers are responsible for reviewing configuration, permissions, data handling and model-provider terms before production use.
